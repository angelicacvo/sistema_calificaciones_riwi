# sistema_calificaciones_riwi
Desarrolla un programa en Python que gestione una serie de calificaciones y estadísticas de manera interactiva.

Desarrollo: El programa interactúa con el usuario a través de la consola, solicitando las calificaciones de un usuario.

Determinar el estado de aprobación:
a. Solicitar al usuario ingresar una calificación numérica (de 0 a 100)
Evaluar si el estudiante ha aprobado o reprobado basándose en la calificación ingresada
b. Calcular el promedio
c. Contar calificaciones mayores
d. Verificar y contar calificaciones específicas

Requerimientos:
Permitir al usuario ingresar una lista de calificaciones (separadas por comas)
Solicitar al usuario ingresar una calificación numérica (de 0 a 100)
Preguntar al usuario por un valor específico
